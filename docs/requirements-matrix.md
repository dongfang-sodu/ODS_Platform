# 需求实现矩阵

最后复核：2026-08-05。状态口径如下：

- `已实现`：已有真实前后端闭环，核心权限或业务规则有自动测试。
- `部分实现`：已有可运行子集，但仍缺少原需求中的页面、流程、权限体验或测试。
- `基线`：只有数据模型、接口骨架或种子数据，尚不能作为完整功能交付。
- `待实现`：尚无可用实现；`待定义`：原始材料不足，需要先补需求。
